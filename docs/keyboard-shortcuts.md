# Keyboard shortcuts

Shortcuts use the **Ctrl** key on Windows and Linux, and **⌘** (Command) on macOS, iPhone, and iPad. The tables list both where they differ.

While the command palette is focused, other app shortcuts are not active.

## General

| Action | Windows / Linux | macOS |
|--------|-----------------|-------|
| Open or close the **command palette** | **Ctrl+P** | **⌘+P** |

## File

| Action | Windows / Linux | macOS |
|--------|-----------------|-------|
| **New** document (after confirmation) | **Ctrl+N** | **⌘+N** |
| **Open Local** (host only) | **Ctrl+O** | **⌘+O** |
| **Open from Google Drive** (host only) | **Ctrl+Shift+O** | **⌘+Shift+O** |
| **Download .tex** | **Ctrl+Shift+S** | **⌘+Shift+S** |
| **Save Now** (when enabled) | **Ctrl+S** | **⌘+S** |

## Edit

| Action | Windows / Linux | macOS |
|--------|-----------------|-------|
| **Undo** | **Ctrl+Z** | **⌘+Z** |
| **Redo** | **Ctrl+Shift+Z** | **⌘+Shift+Z** |
| **Redo** (alternate) | **Ctrl+Y** | **⌘+Y** |
| **Cut** | **Ctrl+X** | **⌘+X** |
| **Copy** | **Ctrl+C** | **⌘+C** |
| **Paste** | **Ctrl+V** | **⌘+V** |
| **Select all** | **Ctrl+A** | **⌘+A** |

## View

| Action | Windows / Linux | macOS |
|--------|-----------------|-------|
| **Compile Now** (preview refresh) | **Ctrl+Shift+C** | **⌘+Shift+C** |

## Menu-only actions

Drive connect/save/move/rename, theme toggles, layout modes, and **Disable Save Now** are available from the **View** and **File** menus or the command palette; they do not all have dedicated global shortcuts.
