# LaTeX Collaborative Editor

A LaTeX editor in your browser, with a live preview and real-time collaboration over peer-to-peer links.
This guide covers how to use it.

![The editor with a project open](assets/screenshots/overview-light.png#only-light)
![The editor with a project open](assets/screenshots/overview-dark.png#only-dark)

## What you can do

- Work on a **project**: a file tree with a main `.tex` file, chapters, images, and `.bib` files.
- See a **preview** that updates as you type.
- **Collaborate** by sending a link. Browsers connect straight to each other, so your document doesn't go through a server of ours.
- **Save** to your browser, to Google Drive (if the site has it set up), or download a `.zip`.
