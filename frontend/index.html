      Read the full docs
      1. Everything the app can do is in these menus. Press Ctrl+P (or Cmd+P) to search them all.
      2. The things you do most, like save, compile, and share, are one click away here.
      3. Your project's files. Drag files in to upload them, and star a .tex file to make it the main file.
      4. Write LaTeX here. Anyone you share with edits the same files at the same time.
      5. The preview updates as you type. Errors show up in the editor and at the bottom of the page.
      6. Click Share to copy a link. Whoever opens it joins you, browser to browser.
      7. See who's connected, whether the preview is up to date, and where and when the project last saved.
      8. Find the docs, keyboard shortcuts, bug reports, and this tour again in Help.
